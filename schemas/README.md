# Schemas

Hand-written JSON Schemas (draft 2020-12, [decision 0008](../docs/decisions/0008-json-schema-as-the-source-of-formats.md)) of every file format (project manifest, `.sec`, `.auto`, `.evt`, `.sched`, `.vars`,
`.hw`, deployment package, board profiles, driver manifests). They are the single source:
Python and TypeScript types and the reference docs are generated from here. Written in phase 2.
