# Security policy

Primum controls physical hardware (motors, relays, mains-powered devices) and runs as a network
service, so security issues matter to us.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and its possible impact. We will acknowledge the
report as soon as possible and keep you informed until it is resolved.

## Supported versions

Primum has no releases yet. Once it does, this section will list which versions receive
security fixes.
